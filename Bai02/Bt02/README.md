## 1. Giới thiệu ứng dụng

LearningApp là ứng dụng học tập được xây dựng bằng React Native trên nền tảng Expo Snack.

Ứng dụng được thiết kế với giao diện thân thiện, hiện đại, giúp sinh viên theo dõi khóa học, môn học và tiến độ học tập.
